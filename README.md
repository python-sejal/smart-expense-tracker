# 💰 Smart Expense Tracker

A mini project developed using Python Tkinter GUI.

---

## 🚀 Features

✔ Add Expense  
✔ Category Dropdown  
✔ Expense List  
✔ Total Expense Calculation  
✔ Clear All Button  

---

## 🛠 Technologies Used

- Python
- Tkinter GUI

---

## 📌 Project Working

1. Enter Amount
2. Select Category
3. Click Add Expense
4. Expense added to list
5. Total updates automatically

---

## 🎯 Purpose

This project helps users manage daily expenses easily.
